# 隐私说明

Tako 测试版会回传匿名的错误和使用统计，帮作者找到大家共同遇到的问题。可以随时关掉。除此之外，Tako 不收集任何东西。

## 回传给作者的内容

默认开着，不弹窗，不打扰你，也不会问你要不要发什么。不想要就右键小章鱼，把“帮助作者优化”前面的勾去掉。

| 内容 | 例子 | 怎么发 |
| --- | --- | --- |
| 版本 | Tako 0.2.7、macOS 15.7 | 每天最多一次，自动 |
| 用量和耗时 | 这一天问了几次、平均几秒、哪个工具用了几次、失败时属于哪种原因（固定词，如“不在前台”“没搜到这个人”“标题对不上”）、连模型重试了几次 | 每天最多一次，自动 |
| 事情的结局 | 这一天做完几件、几件差一步、差的步骤属于哪种原因（如“手在动”）、接着上一句又说了几句、替你写的微信草稿是原样发出、改了再发还是一天都没发（只有次数；草稿去向要开了本机微信读取才有） | 每天最多一次，自动 |
| 第一次设置走到哪 | 看到了哪张卡片（登录、装 Codex、更新 Codex、填 key、模型设置），哪一步没走通、属于哪种原因（如“网络”“端口被占”），用哪种方式接好的（ChatGPT、key、办公智能体），都只有次数 | 每天最多一次，自动 |
| 错误的类型和位置 | `ValueError`、出错的代码行、闪退的异常类型 | 每天最多一次，自动 |
| 固定词表里的标签 | “办公系统｜填表单｜没做到”“想要｜跨软件搬内容”“卡在｜太慢” | 每天最多一次，自动 |
| 你主动说的反馈 | 你在面板里说“告诉作者……” | 先给你看全文，你点“发送”才发，和统计开关无关 |

**什么时候发：** 每天最多一次。刚启动时不发；第一件事做完、开着满一小时或退出 Tako，哪个先到就在那时发，这样只试用一天的人遇到的问题也能让作者看到。没网就留到下次。

**标签是怎么来的：** Tako 会读你在面板里说过的话，判断你在做哪类事、想要什么、卡在哪里。攒够一批或者出了问题才读，每天最多一次。这一步在一个没有任何工具的临时对话里完成，用的是你自己的 Codex 额度。

**发出去之前的检查：** 标签必须完全落在 [feedback.py](../Sources/brain/feedback.py) 的固定词表里，否则丢弃。自动发送的内容里没有任何一句是模型或你写的话。

**永远不发：** 你说的原话、Tako 的回答、窗口内容、截图、文件和文件名、路径、账号、设备标识。

**接收和保存：** 数据发到作者自己在中国大陆的服务器，代码在 [server/feedback_receiver.py](../server/feedback_receiver.py)。它只接受上面这几种固定格式，不记 IP 地址，时间只记到哪一天。

**关掉之后：** 不再统计、不再读你的话、不再发送，本机还没发出去的统计立刻清空。

## 什么会离开你的电脑

| 内容 | 去哪里 | 什么时候 |
| --- | --- | --- |
| 你在面板里说的话、拖进来的文件 | 经 Codex 发给你的模型服务商 | 你发出问题时 |
| 你托付的事、你回应知道了、看看或晚点以及到点/到场/转场和没理会的结局 | 经 Codex 发给你的模型服务商，作为记忆 | 你下一次发出问题时，随已有的一轮一起；不会为提醒另开模型调用 |
| Tako 在一轮答复末尾问的“要我记着吗”，以及你点“好”、说好或没理会的结局 | 经 Codex 发给你的模型服务商，作为托付记忆 | 和上一行一样，你下一次发出问题时随已有的一轮一起；问不问、问什么，是那一轮里模型本来就在做的判断，不另开调用 |
| 你的其他 Agent 用 `tako ask` 转来的话和文件 | 经 Codex 发给你的模型服务商 | 它们交事时，和你在面板里说一样 |
| 窗口截图和窗口里的文字 | 经 Codex 发给你的模型服务商 | Tako 这一轮需要看这个窗口时 |
| 粘在钉钉上时，钉钉窗口里正打开的聊天名和看得见的那几条消息（谁说的、哪些是你自己的、时间行和正文） | 经 Codex 发给你的模型服务商 | 只在你在这个钉钉聊天里开口时，随这一轮一起；别人的消息不触发任何事 |
| 听课转成的文字和笔记要点 | 经 Codex 发给你的模型服务商 | 你让它陪你听课时 |
| Tako 的版本号 | GitHub | 每 6 小时检查一次更新，下载更新时 |
| 匿名统计（见上一节） | 作者的服务器 | 每天最多一次，关掉就不发 |
| 你在面板里说过的话（用来归纳标签） | 经 Codex 发给你的模型服务商 | 每天最多一批，关掉就不读 |
| 你黏上的软件的名字（用来写开场白，不含窗口标题和内容） | 经 Codex 发给你的模型服务商 | 这个软件备用的开场白快用完时问一次；接了微信读取的，当天第一次看微信对话时也问一次，只发“微信”两个字，不含对话名和内容 |
| 模型读到的文件和命令输出 | 经 Codex 发给你的模型服务商 | 你的一轮里，模型能读这台电脑上的文件、跑命令，读到什么就发什么，和你直接用 Codex 一样 |
| 模型决定运行的命令和联网 | 由命令本身决定 | 你的一轮里，模型可以查资料、跑命令 |

模型服务商是第一次打开时接上的那一家：这台 Mac 上的 Codex 已经登录过，就用那个登录；没有、但 WorkBuddy、Qoder 或千问办公已经登录着，就直接用它（面板说一句用的是哪一家，你随时可以在“模型设置…”里换）；都没有才由你来选。登录 ChatGPT 就是 OpenAI，按你 ChatGPT 账号的条款处理；填了 DeepSeek、通义千问（阿里云百炼）、Kimi 或智谱的 key，就是那一家，按你在它那里的账户条款处理并计费；填了中转站，就是那个中转站和它背后的模型服务商。Tako 自己不经过任何中转。

**用 WorkBuddy、Qoder 或千问办公登录时**，上表里“经 Codex 发给你的模型服务商”都换成“经那个应用自带的命令行智能体，发到它自家的服务器”，按你在那一家的账户条款处理，用的是你在那里的积分：

- **WorkBuddy**：发到腾讯（`copilot.tencent.com`），窗口截图跟着请求一起发。它的智能体在 Tako 自己的文件夹 `workbuddy-agent/` 里运行，不存会话记录，你的 WorkBuddy 里看不到也留不下 Tako 的对话。
- **Qoder、千问办公**（两个用同一个 Qoder 登录）：发到阿里（`gateway.qoder.com.cn`），窗口截图先传到 Qoder 在阿里云北京的私有存储，再交给模型，存多久由 Qoder 决定。它会把会话记录存在 `~/.qoder-cn/projects/` 下 Tako 专用的那个文件夹，每一段用完就让它删掉，Tako 启动和退出时也各清一次。
- 这几个智能体自带的系统钩子（如安全扫描、使用统计）会照常向自家服务器上报，Tako 关不掉。
- Tako 不读它们的登录令牌。要知道 WorkBuddy 的登录还能不能用，只读它登录文件里的到期时间；Qoder 的，问它自己的 `status`。

## 什么留在本机

手里有托付时，无论是否粘着窗口，Tako 在本机比较最前窗口的应用名和标题；只有你托付了某段微信聊天且微信在最前时，才截取微信顶部一条并在本机识字比较聊天名；托付了某段钉钉聊天且钉钉在最前时，经辅助功能读钉钉正打开的聊天名（只读名字，不截图、不识字）在本机比较。截取范围可能包含第一条消息的上半部分，识别后丢弃，不用于托付判断。顶部画面没变就不重复识字，没有录屏权限就不匹配、不额外请求权限。画面、识别文字和聊天名不进记录、不落盘、不回传，也不发给模型；不会为到场提醒读取微信数据库或钉钉的消息。

粘在钉钉上时，Tako 经辅助功能读钉钉正打开的是哪个聊天（只读那一行名字），让面板跟着换到你和 Tako 在那个人那里的对话；聊天名只在内存里，面板上的对话照常记进对话记录。钉钉的消息只在你开口时读窗口里看得见的那几条，不截图、不识字、不读钉钉存在本机的任何文件，读到的只是材料，不落盘（对话记录里只有你说的话和 Tako 的回答）。托付与每次递回结局只追加到下面同一份对话记录，从中重建现状，不另建待办库。

定时提醒用 macOS 本地通知，没有远程推送，正文包含你托付的那句话；共享屏幕和锁屏时是否显示通知预览由系统设置控制。默认输入麦克风或摄像头使用中，或系统电源断言表明前台正在阻止显示器休眠、某个进程正在共享或录制屏幕时，Tako 自动安静。递出的泡泡收住，手里泡泡悬停也只显示件数。Tako 只在本机匹配电源断言的类型和名称，不申请新权限、读取屏幕像素、落盘或上报这项观察。安静状态仍保留你主动发问的答复和点开面板的操作。未发布相关断言且没用到可见设备的静音录屏、窗口共享或虚拟设备可能漏检；断言出现到下一次检查之间也可能暂时有字。系统通知正文及预览受 macOS 管理。手动禁言及隐藏状态保存在运行目录，重启恢复；系统通知跟随专注模式，Tako 不读取专注状态。

为了识别说话键、组合键和画圈，辅助功能事件监听会看到全局修饰键、按键及鼠标按钮信息；普通文字按键只在你主动开启说话输入时处理，按键事件不写入记录或回传。说话时 Tako 自己打开的默认麦克风不触发自动禁言；系统设备状态不能区分同时使用同一个麦克风的其他应用。

**提醒事项和日历（自愿接上）：** Tako 帮到你一次之后、这台 Mac 上有聊天软件时，桌面面板会在某一天出现一行「你自己记的待办和日程里写到谁，见到TA、开会前我也提你一句。」；只有你点了“好”，系统才会问你（系统的弹窗里叫提醒事项和日历）。那天没点，这一行就不再出现；拒绝了也不再提。接上之后，Tako 读你还没完成的提醒事项和接下来一天的日程（标题、备注、开始时间、与会者的名字），只在本机内存里和你已有的聊天名比对：提醒里写到谁，你打开和TA的聊天时 Tako 说一行；开会前十分钟，与会者或标题里有你答应过什么事的人，Tako 说一行，说的是 Tako 自己记着的那件事。默认情况下，提醒事项和日程的文字不进对话记录、不进日志、不发给模型、不回传；如果你另外同意下面的记忆来源邀请，相关新内容会发给你接的模型来整理记忆；你在提醒事项里勾掉了，Tako 这边跟着消失。你对某条提醒点了“✓ 做完了”，Tako 只记下那条提醒的一个不可还原的编号（`ladder.json`），以后不再为它说话。日程只当时刻用，别人发来的邀请不会变成提醒。

**你的其他 Agent 和脚本：** Tako 不看、不碰任何 Agent 自己的文件夹，也不问你。只有你的主目录里已经有 `~/.local/bin`（放命令行工具的常见位置）时，Tako 每次启动在那里放一个三行的 `tako` 命令（指向 app 里的 `tako_cli.py`，文件里有 Tako 的标记）；那里已经有一个不是 Tako 放的 `tako`，就不动它。任何 Agent 或脚本用 `tako --help` 就知道什么时候、怎么把事交给 Tako。不想要它，删掉这个文件即可（下次启动会再放回；要彻底不放，把它换成你自己的同名文件）。

**Tako 的文件夹**（默认桌面上的 `Tako`，右键小章鱼 →“做过的事…”→“换位置…”可以换）里分两块，都是你的，随时可以看或删：

- `对话记录/`：一天一份 Markdown（`YYYY-MM-DD.md`），记着面板上显示过的内容：你说的话（以及你的 Agent 替你转来的话）和 Tako 的回答、笔记，每件事的结局、做出的文件和它改过的别处文件。不单独存聊天记录和窗口内容，但回答里可能引用你让它看的聊天或文件。每个文件只有你本人能读（权限 600），Tako 不会删它。它用来让面板在重启或更新后不清空、让 Tako 按出处找回原话，以及“做过的事”里的历史。这个文件夹在“桌面”或“文稿”里、你又开了 iCloud 的“桌面与文稿”同步时，这些记录会跟着同步到 iCloud。
- `产出文件/`：Tako 做出来交给你的文件，按日期和窗口分。Tako 不会删，用不着了你自己删；删掉以后对话记录还在，只是标“已不在”。

运行数据都在 `~/Library/Application Support/Tako/`，随时可以看或删：

- `voice.md`：从你改过的草稿里学到的写法习惯，纯文本，不存原句、人名和数字。
- `metrics.jsonl`：只有数字（耗时、token）和固定词（工具名、某步卡住的原因、应用的 bundle id），没有内容，不离开这台电脑。
- `feedback.json`：匿名统计的开关、还没发出去的数字和标签。
- `ontology.jsonl`：主体和项目的追加流水（权限 600），保存字段、证据引用及支持该判断的逐字摘录。旧 `judgments.jsonl` 保留用于回查。读取位置放在 `ontology-positions.json`，待办仍在对话里的托付记录。
- `agent.json`：给你的其他 Agent 的门牌，只有本机端口和一个只开 `/agent/` 接口的令牌，只有你本人能读（权限 600），每次启动换新。
- `working.json`：正在做的事的编号，没有内容，让 Tako 重启前知道会不会打断它。
- `quiet.json`：手动禁言和隐藏开关；自动安静状态不保存。
- macOS 用户偏好：说话键和使用提示的开关、已用过的功能，不包含说话内容。
- `ladder.json`：Tako 主动出现的东西走到哪：第一次试用到了哪一步、什么时候第一次帮到你、哪几样邀请哪天出过、连着几次没理会“要我记着吗”和最后一次的时间、你说过别再问、提醒事项和日历接上还是拒绝、你放下的提醒的不可还原编号。另含每天主动递出次数和其他记忆来源的同意状态。只有阶段、数字、日期和开关，没有任何人说的话。
- `work/`：每件事干活时的草稿：截图、脚本、中间文件、改稿副本。一周后自动删掉。
- `greetings.json`：每个软件备用的开场白和黏过的次数，以及微信对话当天那批开场白。
- `backups/`：替换文件前的备份，30 天后自动移到废纸篓。旧版的 `asked.json`、`conversations.json` 升级时写进对话记录，原文件也放在这里。
- `provider.json`：你填的模型 key 和服务商，只有你本人能读（权限 600），只在启动 Codex 时交给它；改回 ChatGPT 登录就删掉。
- `config.json`、`about-me.md`：你自己写的设置和背景（可选）。
- `inbox/`：你粘贴进面板的图片，下次启动时清空。
- `panel.log`、`server.err`：这次运行的诊断记录（动作、软件的 bundle id、报错位置），不含窗口内容和你说的话；`panel.log` 每次启动清空。
- `codex-state/`：Tako 专用的 Codex 状态库，每次启动重建。
- `office.json`：你选了用哪个办公智能体登录（只有名字，没有令牌）；改回 ChatGPT 或填 key 就删掉。
- `office-sessions/`、`workbuddy-agent/`、`office-tools.sock`：办公智能体运行的文件夹、WorkBuddy 智能体自己的设置和缓存、Tako 把工具交给它的本机通道（只有你本人能打开）。

按一下右 ⌥ 开始说话时使用系统语音识别，并强制要求本机识别；当前语言或设备不支持时改用打字。音频只在内存中处理，不写文件、不交给联网识别；识别出的文字在再次按右 ⌥ 或回车交代后，和打字一样发给你选的模型并进入对话记录。

听课的声音每段转完文字就删除，不上传。窗口截图和窗口里的文字只在内存里，发给模型后不写到磁盘。

**Codex 自己的日志：** Codex 默认把工具结果连同完整截图记进 `~/.codex/logs_2.sqlite`，最长保留 10 天，日志级别关不掉。这个文件这台电脑上的其他程序都能读。Tako 给自己的 Codex 单独建库，日志一行不留，所以 Tako 这一轮的内容不会进这个文件。排查问题时可以在 `config.json` 里打开 `keep_codex_log`，这时日志（含截图）留在 `codex-state/`，下次启动清空。

**0.2.14 之前的 Tako 没有这样做：** 旧记录还在 `~/.codex/logs_2.sqlite`，Codex 最长 10 天后删掉，文件里被删的部分要等新内容覆盖才真正消失。想马上清掉，退出 Tako、Codex 和 ChatGPT 后删除 `~/.codex/logs_2.sqlite*`，Codex 下次启动会重建。你直接用 Codex 或 ChatGPT 时的日志由它们自己管，Tako 关不掉。

## 权限和用途

| 系统权限 | 用途 |
| --- | --- |
| 屏幕录制 | 看窗口；听课时采集这个应用的声音 |
| 辅助功能 | 点按钮、输入、挪窗口；粘在钉钉上时读它正打开的聊天和看得见的消息 |
| 自动化 | 第一次通过脚本操作某个应用时系统会问你 |
| 桌面、文稿、下载 | 你让它处理这些位置的文件时；对话记录和做好的东西默认放在桌面的 Tako 文件夹 |
| 通知 | 告诉你有新版本和到点的托付 |
| 提醒事项、日历 | 只在你点了“好”之后问；见到提醒里写到的人、开会前十分钟提一句，只在本机比对 |
| 麦克风、语音识别 | 按一下右 ⌥ 开始说话时使用，首次使用时系统询问 |

## 其他记忆来源（另行同意）

Tako 帮过一次之后，可以邀请你让它看看其他助手里聊过的事、日历和提醒事项，并明确说明需要的内容会交给你接的模型。只有你点“好”，才读取本机 Codex、Claude 的会话消息；日历和提醒事项还需要系统本身已有授权。这次同意记录在本机 `ladder.json` 的 `memory_access`，改成 `declined` 就停止后续读取。未同意时不会扫描会话正文。只读已空闲的会话消息，不读工具输出、密钥、登录文件、私有应用数据库，不写回其他助手目录。

正文在原处读取，写入 `ontology.jsonl` 的是有出处的判断及其依据摘录。相关痕迹随整理请求交给你接的模型服务商，作者的反馈入口不接收这些内容。启用外部本体后，Tako 从配置的本机环回接口或来源快照读本体，最多 2,000 字的索引随主人这一轮交给选定的模型。显式纠正的字段、原话和面板引用发回该本机服务。外部模式停用本机本体日志和推断。

## 模型能做什么

- **你说的一轮：** Codex 的沙箱里只读（用 WorkBuddy、Qoder 时是 Tako 自己的同一种沙箱：它们自带的命令、写文件、发消息、生图等工具全部关掉，只留网页搜索，换成 Tako 的工具），命令默认在本轮的草稿目录里跑，交给你的成品写到 Tako 文件夹的 `产出文件/`。要改别处的文件，Tako 先把原件备份到 `backups/` 再放行；普通命令出沙箱直接放行。删除文件、往外发送或上传、推送 git、改系统设置、结束进程、用 osascript 操作别的应用，面板会弹卡片问你。把文件传进网页的上传框也一样：一件事里第一次往一个网站传，卡片列出是哪些文件、传到哪个网站，你点了才传，文件只交给那个网页，不经过 Tako 的作者。如果你在 Codex 里配置过放行规则，那些规则仍然生效。
- **发送：** 永远拒绝，批准也不行。
