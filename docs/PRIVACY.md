# 隐私说明

Tako 测试版会回传匿名的错误和使用统计，帮作者找到大家共同遇到的问题。可以随时关掉。除此之外，Tako 不收集任何东西。

## 回传给作者的内容

默认开着，不弹窗，不打扰你，也不会问你要不要发什么。不想要就右键小章鱼，把“帮助作者优化”前面的勾去掉。

| 内容 | 例子 | 怎么发 |
| --- | --- | --- |
| 版本 | Tako 0.2.7、macOS 15.7 | 每天最多一次，自动 |
| 用量和耗时 | 这一天问了几次、平均几秒、哪个工具用了几次、连模型重试了几次 | 每天最多一次，自动 |
| 事情的结局 | 这一天做完几件、几件差一步、差的步骤属于哪种原因（如“手在动”）、接着上一句又说了几句（只有次数） | 每天最多一次，自动 |
| 错误的类型和位置 | `ValueError`、出错的代码行、闪退的异常类型 | 每天最多一次，自动 |
| 固定词表里的标签 | “办公系统｜填表单｜没做到”“想要｜跨软件搬内容”“卡在｜太慢” | 每天最多一次，自动 |
| 你主动说的反馈 | 你在面板里说“告诉作者……” | 先给你看全文，你点“发送”才发，和统计开关无关 |

**标签是怎么来的：** Tako 会读你在面板里说过的话，判断你在做哪类事、想要什么、卡在哪里。攒够一批或者出了问题才读，每天最多一次。这一步在一个没有任何工具的临时对话里完成，用的是你自己的 Codex 额度。

**发出去之前的检查：** 标签必须完全落在 [feedback.py](../Sources/brain/feedback.py) 的固定词表里，否则丢弃。自动发送的内容里没有任何一句是模型或你写的话。

**永远不发：** 你说的原话、Tako 的回答、窗口内容、截图、文件和文件名、路径、账号、设备标识。

**接收和保存：** 数据发到作者自己在中国大陆的服务器，代码在 [server/feedback_receiver.py](../server/feedback_receiver.py)。它只接受上面这几种固定格式，不记 IP 地址，时间只记到哪一天。

**关掉之后：** 不再统计、不再读你的话、不再发送，本机还没发出去的统计立刻清空。

## 什么会离开你的电脑

| 内容 | 去哪里 | 什么时候 |
| --- | --- | --- |
| 你在面板里说的话、拖进来的文件 | 经 Codex 发给 OpenAI | 你发出问题时 |
| 你的其他 Agent 用 `tako ask` 转来的话和文件 | 经 Codex 发给 OpenAI | 它们交事时，和你在面板里说一样 |
| 窗口截图和窗口里的文字 | 经 Codex 发给 OpenAI | Tako 这一轮需要看这个窗口时 |
| 听课转成的文字和笔记要点 | 经 Codex 发给 OpenAI | 你让它陪你听课时 |
| Tako 的版本号 | GitHub | 每 6 小时检查一次更新，下载更新时 |
| 匿名统计（见上一节） | 作者的服务器 | 每天最多一次，关掉就不发 |
| 你在面板里说过的话（用来归纳标签） | 经 Codex 发给 OpenAI | 每天最多一批，关掉就不读 |
| 你黏上的软件的名字（用来写开场白，不含窗口标题和内容） | 经 Codex 发给 OpenAI | 这个软件备用的开场白快用完时问一次；接了微信读取的，当天第一次看微信对话时也问一次，只发“微信”两个字，不含对话名和内容 |
| 模型读到的文件和命令输出 | 经 Codex 发给 OpenAI | 你的一轮里，模型能读这台电脑上的文件、跑命令，读到什么就发什么，和你直接用 Codex 一样 |
| 模型决定运行的命令和联网 | 由命令本身决定 | 你的一轮里，模型可以查资料、跑命令 |

这些内容由 OpenAI 按你 ChatGPT 账号的条款处理。

## 什么留在本机

运行数据都在 `~/Library/Application Support/Tako/`，随时可以看或删：

- `voice.md`：从你改过的草稿里学到的写法习惯，纯文本，不存原句、人名和数字。
- `metrics.jsonl`：只有数字（耗时、token）和固定词（工具名、某步卡住的原因、应用的 bundle id），没有内容，不离开这台电脑。
- `feedback.json`：匿名统计的开关、还没发出去的数字和标签。
- `agent.json`：给你的其他 Agent 的门牌，只有本机端口和一个只开 `/agent/` 接口的令牌，只有你本人能读（权限 600），每次启动换新。
- `asked.json`：最近 7 天你交代给 Tako 的事：你自己说的原话（以及你的 Agent 替你转来的话）、在哪个窗口或对话说的、作品目录、做出的文件名和结局。用来在重启或更新后还记得没做完的事，不含窗口和聊天里的内容，只有你本人能读（权限 600），不离开这台 Mac。
- `greetings.json`：每个软件备用的开场白和黏过的次数，以及微信对话当天那批开场白。
- `backups/`：替换文件前的备份。
- `config.json`、`about-me.md`：你自己写的设置和背景（可选）。
- `inbox/`：你粘贴进面板的图片，下次启动时清空。
- `panel.log`、`server.err`：这次运行的诊断记录（动作、软件的 bundle id、报错位置），不含窗口内容和你说的话；`panel.log` 每次启动清空。
- `codex-state/`：Tako 专用的 Codex 状态库，每次启动重建。

听课的声音每段转完文字就删除，不上传。窗口截图和窗口里的文字只在内存里，发给模型后不写到磁盘。

**Codex 自己的日志：** Codex 默认把工具结果连同完整截图记进 `~/.codex/logs_2.sqlite`，最长保留 10 天，日志级别关不掉。这个文件这台电脑上的其他程序都能读。Tako 给自己的 Codex 单独建库，日志一行不留，所以 Tako 这一轮的内容不会进这个文件。排查问题时可以在 `config.json` 里打开 `keep_codex_log`，这时日志（含截图）留在 `codex-state/`，下次启动清空。

**0.2.14 之前的 Tako 没有这样做：** 旧记录还在 `~/.codex/logs_2.sqlite`，Codex 最长 10 天后删掉，文件里被删的部分要等新内容覆盖才真正消失。想马上清掉，退出 Tako、Codex 和 ChatGPT 后删除 `~/.codex/logs_2.sqlite*`，Codex 下次启动会重建。你直接用 Codex 或 ChatGPT 时的日志由它们自己管，Tako 关不掉。

## 权限和用途

| 系统权限 | 用途 |
| --- | --- |
| 屏幕录制 | 看窗口；听课时采集这个应用的声音 |
| 辅助功能 | 点按钮、输入、挪窗口 |
| 自动化 | 第一次通过脚本操作某个应用时系统会问你 |
| 桌面、文稿、下载 | 你让它处理这些位置的文件时；做好的东西默认放在桌面的 Tako 文件夹 |
| 通知 | 告诉你有新版本 |

## 模型能做什么

- **你说的一轮：** Codex 的沙箱里只读，文件默认写到本轮的作品目录。要改别处的文件，Tako 先把原件备份到 `backups/` 再放行；普通命令出沙箱直接放行。删除文件、往外发送或上传、推送 git、改系统设置、结束进程、用 osascript 操作别的应用，面板会弹卡片问你。如果你在 Codex 里配置过放行规则，那些规则仍然生效。
- **发送：** 永远拒绝，批准也不行。

发现安全问题请通过 [GitHub Security Advisories](https://github.com/JoeSangAI/Tako/security/advisories/new) 私下告知。
